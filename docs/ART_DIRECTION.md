# 왕도 아트 디렉션

## 유지할 기준

현재 카드·전신·인연 그림의 부드러운 반실사 채색, 피부·머리카락·비단의 광택, 성인 캐릭터의 몸선과 인물 중심 구도를 기준으로 삼는다. 기존 얼굴과 머리색을 보존하면서 직업·종족·성격을 옷의 형태와 손의 행동으로 더 분명하게 만든다. 16명별 기준은 [CHARACTER_GUIDE.md](CHARACTER_GUIDE.md)에 있다.

왕도는 조선풍 설화 판타지다. 기와·목구조·옷깃·매듭·노리개·갓·도장·장부·국악기처럼 장면에 필요한 구체적인 단서를 사용한다. 모든 공간과 인물을 같은 금장식·등불·꽃잎·긴 비단으로 채우지 않는다. 역사 복식을 그대로 복원하기보다 역할을 읽을 수 있는 판타지 복식으로 일관되게 그린다.

## 교체한 식객 5명

청연·윤슬·벼리·단희·오련의 카드·전신·인연 3·5단계 20장을 교체했다. 무영·월하는 카드·전신의 기본 표정을 별도로 수정했다. 다음 표는 새 카드·전신에 적용된 실제 구별점이다. 완료된 전체 42장과 아직 유지하는 그림은 [ART_UPDATE.md](ART_UPDATE.md)에 구분했다.

| 식객 | 서로 구별하는 핵심 | 적용한 옷·색·소품 | 자세·표정 |
| --- | --- | --- | --- |
| 청연 | 넓은 소매와 가벼운 여백 | 하늘색·상아의 긴 겉옷, 금장을 줄인 구름 리본, 붓·문서통 | 곧게 선 차분한 서기관, 문서를 다루는 손 |
| 윤슬 | 굵은 옆땋은 머리와 손 사이의 실 | 남색·상아 작업치마와 정리된 겹옷, 나무 북과 한 줄의 실 | 차분히 집중한 눈, 두 손에 북과 실을 들어 직녀의 역할을 설명 |
| 벼리 | 짧은 집행복·장화·창의 직선 | 상아·먹색의 짧은 재킷과 튜닉, 옅은 보라색·금색 갑주 포인트. 긴 드레스와 베일을 정리 | 양발을 딛고 창을 세운 엄격하고 자신 있는 집달관 |
| 단희 | 짧은 겹옷과 감투를 내미는 손 | 옥색·자두색 겹옷, 허리띠·스타킹·장화·감투 주머니 | 비스듬한 미소와 장난스러운 눈썹, 허리에 손을 짚은 감투 상인 |
| 오련 | 높은 깃과 허리가 잡힌 상인 겉옷 | 검정·구리의 긴 맞춤 겉옷, 짙은 녹색·진홍 안감, 주판·거래 문서 | 문서와 주판을 든 절제된 자신감 |

다섯 명은 색뿐 아니라 소매·옷길이·머리 형태·소품으로 구별한다. 초기 시안의 단희 접부채와 벼리 슬레이트 보라 주색은 이번 최종 카드·전신의 핵심으로 채택하지 않았다. 후속 생성에서도 최종 그림을 기준으로 삼고, 짧은 설명에 남은 초기 색·소품 지시와 충돌하면 이 표와 실제 카드·전신을 우선한다.

## 인물의 공통 규격

- 카드: 세로 2:3, 머리부터 허벅지 중간까지. 얼굴과 대표 소품을 우선한다. 기존 배포 규격은 768×1152다.
- 식객 전신: 투명 배경, 머리·발·종족 표식·소품의 끝까지 포함. 기존 배포 규격은 800×1200이다. 기준 크기를 바꿀 때는 로비와 이야기 배치도 함께 확인한다.
- 인연 CG: 세로 2:3을 기준으로 얼굴과 손의 행동을 크게 둔다. 대사 상자가 놓일 위치에는 핵심 표정과 소품을 두지 않는다.
- 카드·전신·CG를 같은 캐릭터 단위로 검수한다. 새로운 의상이 필요하면 어느 장면의 의상인지 기록한다. 얼굴과 종족 표식은 의상 변화와 무관하게 유지한다.

## 인연 그림

3단계는 그 식객의 생활과 비밀을 가까이서 보게 되는 장면, 5단계는 관계가 깊어진 표정과 거리의 변화를 보여 주는 장면으로 잡는다. 장소를 바꾸는 데 그치지 않고 손이 하는 행동과 상대에게 허용하는 거리가 달라야 한다. 아래는 후속 제작에도 쓰는 구도용 방향이다. 교체한 5명 외의 인연 CG는 이번에 바꾸지 않았다. 실제 장면은 해당 인연 대본의 사건과 소품을 확인해 선택한다.

| 식객 | 반복 구도 대신 보여 줄 행동·장소의 단서 |
| --- | --- |
| 백설 | 접이 거울과 이름의 단서, 꼬리로 만든 둘만의 작은 공간 |
| 무영 | 무기 손질·전투 뒤 갑주를 풀어 놓는 휴식, 경계가 누그러지는 눈 |
| 소담 | 공동 곡간·작은 부엌·장부를 함께 맞추는 손 |
| 해륜 | 텅 빈 재판 자리·인장·오판 기록을 건네는 손 |
| 오련 | 상단의 계약 책상·주판·닫은 가게에서 장부를 덮는 행동 |
| 연화 | 빈 무대·연습 뒤 멈춘 발·리본을 정리하는 손 |
| 불새 | 식어 가는 화로·완성한 생활 도구·장갑을 벗는 손 |
| 청연 | 고쳐 쓴 하늘 문서·서고의 창가·문서통을 내려놓는 행동 |
| 서린 | 호위가 끝난 문턱·북방 통행패·칼집에서 멀어지는 손 |
| 금영 | 밀서·등불을 가린 손·상대에게만 드러내는 편지의 봉인 |
| 단희 | 문 닫은 감투 가게·감투 속 기억·감투를 내려놓고 허풍을 거두는 얼굴 |
| 해진 | 물길 지도·진주 인장·물가의 협상 자리에서 마주 앉는 거리 |
| 월하 | 명부·기한이 지워진 기록·꼿꼿한 자세가 아주 조금 풀리는 순간 |
| 바리 | 의식을 마친 빈 자리·방울을 내려놓는 손·혼을 보낸 뒤의 고요 |
| 윤슬 | 베틀·느슨해진 매듭·상대 손에 실 한 올을 걸어 주는 행동 |
| 벼리 | 집행을 마친 관청·세워 둔 창·표정과 말투에서 드러나는 당황 |

같은 계열의 장소를 써도 구도·시간대·행동이 같아지지 않게 한다. 기존 성인 로맨스의 매력은 유지하되 모두를 같은 미소와 같은 등잔 아래 포즈로 만들지 않는다. 입맞춤과 함께 보낸 밤의 암시까지 표현하고, 맨몸이나 성행위를 직접 묘사하지 않는다.

## 배경·적·UI와의 합성

배경은 공간의 깊이와 지역 차이를, 인물은 얼굴·직업·감정을 맡는다. 인물 뒤의 밝은 창·등불·구름이 얼굴과 경쟁하면 명도를 낮추거나 위치를 조정한다. 전투 배경의 중앙·하단은 적과 효과가 놓일 무대로 비운다.

적 이미지는 실제 전투 화면에서 필요한 머리·손·무기·발의 범위를 확인해 제작한다. 오래된 반신 적을 전신처럼 확대해 잘린 무릎이나 소품이 보이게 하지 않는다. 보스는 크기뿐 아니라 자세·주요 소품·명도 차이로 구별하고, 졸개는 서로의 윤곽을 가리지 않게 한다. 화면 배치를 확인하기 전에는 원본만 보고 최종 합성이 통과했다고 기록하지 않는다.

UI 뒤에서는 장식보다 정보의 명도 대비와 여백을 우선한다. 얼굴·손·대표 소품이 자원 표시, 이름표, 대사 상자와 겹치지 않는지 휴대폰 세로 화면에서 확인한다. 스타일을 바꿀 때는 배경·인물·아이콘·효과를 한 화면에 모아 본다.

## 제작·교체 기록

1. 기존 인물 그림, 공통 화풍 기준, 변경할 항목을 정한다. 얼굴·체형·머리색을 유지하는 항목으로 명시한다.
2. 카드와 전신을 한 쌍으로 비교한다. 역할 소품·실루엣·표정·주색이 기준표와 맞아야 한다.
3. 밝은 바탕·짙은 바탕에서 투명도를 확인하고 손·발·소품을 확대 검수한다. 알파가 0인 픽셀에 남은 RGB가 일부 뷰어에서 보이는 것만으로 결함 판정을 내리지 않는다.
4. 로비·목록·이야기·전투 중 사용되는 화면에서 크기·자르기·겹침을 확인한다. 직접 확인한 화면과 아직 확인하지 못한 화면을 구분해 적는다.
5. 교체한 경로와 대응하는 카드·전신·CG, 변경 이유와 남은 작업을 기록한다. 실제 그림 교체 여부와 목표 문서를 혼동하지 않는다.

출력 파일의 이름·경로와 게임 데이터의 식객 ID는 유지한다. 이 문서는 게임 규칙·밸런스·이야기 설정 변경 지시가 아니다.
