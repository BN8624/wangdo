# 식객 디자인 기준

현재 카드·전신·인연 그림의 부드러운 반실사 채색을 왕도의 기준으로 쓴다. 얼굴·머리카락·직물의 질감, 성인 캐릭터의 매력과 인물 중심 구도를 유지하면서 직업·종족·성격이 더 잘 구별되게 다듬는다. 전체 제작 기준은 [ART_DIRECTION.md](ART_DIRECTION.md)를 함께 본다.

## 기준의 우선순위

1. 얼굴·체형·머리색·종족 표식은 해당 식객의 기존 카드와 전신 그림을 기준으로 삼는다.
2. 청연·윤슬·벼리·단희·오련은 카드·전신·인연 3·5단계 20장을 새 디자인으로 교체했다. 무영·월하는 카드·전신 4장의 기본 표정을 정리했다. 나머지 9명과 무영·월하의 인연 CG는 기존 그림을 유지하며, 아래 표의 역할 강화는 후속 제작 기준이다. 완료 경로와 검증 범위는 [ART_UPDATE.md](ART_UPDATE.md)에 기록했다.
3. `content/heroines.json`의 `art`는 그림 제작용 짧은 설명이다. 오래된 설명과 아래 표가 다르면 표와 기준 그림을 따른다. 나이·종족·성격·이야기 설정은 기존 콘텐츠를 유지한다.

초기의 '모두 현대 패션을 섞는다', '금장식을 전부 없앤다', '소담은 연보라 원피스', '무영은 청록 장교 재킷' 주문은 현재 그림과 달라 이 기준으로 대체한다. 기존 그림의 자수·보석·금속은 캐릭터의 재료로 유지하되, 새 시안에서는 장식의 수와 면적을 줄여 얼굴·직업 소품이 먼저 읽히게 한다.

## 공통 규칙

- **같은 인물 유지:** 모두 설정에 명시된 성인 여성이다. 기존 얼굴, 머리색, 성인 체형의 비율을 유지한다. 차별화를 위해 얼굴을 다른 사람처럼 바꾸거나 체형을 일괄 축소하지 않는다.
- **출신이 형태를 정한다:** 직업에 맞는 옷의 윤곽과 손의 행동을 먼저 정한다. 무관의 갑주, 직녀의 작업 앞치마, 행수의 맞춤 겉옷, 선녀의 넓은 소매를 색만 바꾼 같은 옷으로 만들지 않는다.
- **작은 화면에서 구별:** 머리 형태·옷 윤곽·소품 중 둘 이상이 이웃 식객과 달라야 한다. 전신을 검은 실루엣으로, 카드를 작은 썸네일로 나란히 보아 확인한다.
- **장식의 위계:** 얼굴 주변의 대표 장식 하나와 허리·가슴 중 한 곳의 상징을 중심으로 잡는다. 기존의 금속·자수 질감은 남기되 전신을 같은 밀도로 채우지 않는다. 날리는 천은 선녀·무희처럼 이유가 있는 식객에게 집중한다.
- **표정의 차이:** 기본 그림은 성격을 보여 준다. 무영·월하·벼리의 기본 표정을 일괄 미소로 만들지 않는다. 다정해지는 변화는 대화·인연 그림에서 보여 준다.
- **매력과 구도:** 기존의 몸선, 성인 패션, 피부·직물의 부드러운 광택을 유지한다. 얼굴과 역할 소품을 읽을 수 있게 손·팔·천의 겹침을 정리한다. 눈높이 시점, 옷을 갖춰 입은 인물 표현을 기준으로 한다.

## 카드·전신·인연 그림의 연결

- **카드:** 세로 2:3, 머리부터 허벅지 중간까지. 얼굴과 역할 소품을 크게 보여 준다. 캐릭터 장소를 암시하는 차분한 배경과 눈높이 시점, 기존의 부드러운 조명을 유지한다.
- **전신:** 머리부터 발끝과 소품 끝을 모두 포함하는 투명 배경. 카드와 얼굴·머리·의상 구조를 맞춘다. 발이 안정적으로 놓이고, 몸 밖으로 뻗은 천과 소품이 다른 식객의 공간을 과하게 차지하지 않게 한다.
- **인연:** 기존의 따뜻한 채색과 성인 로맨스 분위기를 유지한다. 장소·손의 행동·표정에 해당 식객의 이야기 이유가 있어야 한다. 모든 3단계를 물가, 모든 5단계를 등잔 아래 같은 자세로 반복하지 않는다. 장면 선정 기준은 [ART_DIRECTION.md](ART_DIRECTION.md#인연-그림)를 따른다.
- **교체 순서:** 새 디자인은 카드와 전신을 한 쌍으로 맞춘다. 인연 CG는 동일 의상 장면이면 같은 구조로 맞추고, 이야기상 다른 옷이면 별도 의상임을 제작 기록에 명시한다. 이전·신규 그림을 임의로 섞어 새 정본으로 표시하지 않는다.

## 제작과 검수

기준 그림과 해당 식객의 기존 그림을 함께 보고 만든다. 부분 수정은 얼굴·몸선·화풍을 고정하고 바꾸는 항목만 적는다. 시안을 늘리는 것보다 역할·실루엣·표정이 목표에 맞는지 먼저 확인한다.

1. 카드·전신에서 같은 인물인지, 눈·머리색·종족 표식이 유지됐는지 확인한다.
2. 작은 카드와 검은 실루엣으로 보고 옆 식객과 구별되는지 확인한다.
3. 손가락·소품 잡는 방향·발의 접지·겹친 천의 구조를 확대해 본다.
4. 투명 그림은 밝은 바탕과 짙은 바탕에 각각 합성해 확인한다. 알파가 0인 픽셀의 숨은 RGB를 표시 도구가 보여 주는 현상을 실제 누끼 결함으로 판단하지 않는다.
5. 로비·식객 목록·이야기에 실제 배치해 얼굴, 발, 소품과 UI의 겹침을 확인한다. 검사 범위와 결과를 남긴다.

## 이야기·세계관

이야기는 주인공의 1인칭이다. 이벤트 그림은 주인공이 보고 있는 장면으로 그리고, 필요한 경우 주인공의 손이나 소매만 화면 가장자리에 보인다. 식객은 장면에 맞게 보는 사람과 시선을 맞춘다.

인연 4단계의 첫 입맞춤과 5단계의 함께 보낸 밤의 암시는 기존 설정을 유지한다. 감정과 관계는 표정·거리·손의 행동·조명으로 표현하고, 맨몸이나 성행위를 직접 묘사하지 않는다. 성인 확인 화면의 유무와 관계없이 같은 표현 기준을 쓴다.

## 적과 배경

적은 조선풍 세계관의 동아시아 인물·설화 존재로 표현한다. 적 인물의 얼굴·옷·소품은 해당 역할과 지역을 설명해야 한다. 전투 배경은 가운데·아래를 인물과 효과가 놓일 무대로 비우고, 적 이미지는 현재 전투 화면의 실제 배치에 맞는 별도 규격을 따른다. 과거의 '적은 무조건 허벅지까지만' 주문을 새 화면에 일괄 적용하지 않는다. 전체 규격과 합성 검수는 [ART_DIRECTION.md](ART_DIRECTION.md)를 기준으로 한다.
