## 정한 것 (2026-10-27, 사용자 답)

1. **GPT**: 구독(ChatGPT)으로 쓴다. 세션마다 `npm i -g @openai/codex` 뒤 `codex login --device-auth`로 사용자가 브라우저에서 코드를 넣는다.
   - 도트 원본 묶음(Ninja Adventure)은 itch.io 가입 없이 `node scripts/fetch-ninja-pack.cjs <zip>`으로 받는다.
2. **백설 단독 화**: 넣었다. 1화와 무영 화 사이 2화 '여우가 사람 사는 법'. 상황마다 전투를 넣었다(사용자 요청): 장터 파락호, 주막 흑운채 술꾼, 밤 도깨비불. 고를 거리는 떡값·파락호·외상값·거울 넷이고 깃발로 반응이 갈린다. 3화 적은 레벨을 3씩 올렸다.
3. **기술**: A(빚을 받아낼수록 담보 잡힌 힘이 돌아옴). 주인공·무영·소담 모두 같은 방식. 컷인은 기술을 쓸 때마다 나오고 메뉴에서 켜고 끈다.
4. **10월 25일 그림**: 6장을 장면 그림으로 넣고, 대화창 백설·무영을 기준 전신으로 바꿨다. 글은 그림에 맞춰 고쳤다(밤길 백설은 손을 잡아끎, 무영의 뿔).
5. **'송 대감네'**: 바꿨다.

## 정한 것 (2026-10-28)

- **기술 기반**: 맵은 Tiled로 그리고(`docs/MAPS.md`), 화면 효과는 웹용 2D 엔진(PixiJS)으로 넣는다. 고도 엔진은 쓰지 않는다(웹 먼저 전략, 첫 로딩, 다시 짜는 비용).
- **도트**: 16px를 유지하고 연출로 올린다. 2026-10-28에 계획한 것을 모두 넣었다: Tiled → PixiJS(맵·전투) → 밤·동굴 조명(`light.ts`) → 발밑 그림자·나무와 지붕 뒤 가림 → 전투 연출(흔들림·치명타 번쩍임·기술별 효과) → 떠다니는 것(`particles.ts`: 낙엽·굴 먼지·굴뚝 연기·반딧불·발밑 먼지) → 조선풍 소품(돌담·싸리 울타리·솟대·빨래·볏단) → 서 있을 때 숨쉬기.
- **출전 방식**(4화 소담 합류 때 넣는다): 출전은 주인공 + 식객 셋, 대기 식객도 경험치를 다 받는다. 식객마다 집안일(전투 밖 쓸모)이 있다. 데려간 식객에 따라 잡담과 장면이 갈린다. 화마다 중심 식객은 반드시 출전. 한 부에 식객 3~4명.

- **예전 게임 정리**(2026-10-28): 예전 수집형 게임을 내리고 코드·테스트·그림을 지웠다. 첫 주소가 v3. 마지막 상태는 `v2-final` 브랜치. 테스트는 시제품 25 + 전투 엔진 11 = 36개. 예전 게임이 설치한 서비스 워커는 `public/sw.js`가 캐시를 지우고 스스로 해제한다.

- **4화 '우렁각시의 밥상'**(2026-10-29): 원고 3화를 시제품에 옮겼다. 수위는 최대한 올린다(사용자 결정). 소담 합류(도트: Ninja Adventure Woman을 고쳐 씀, 대화창 전신·컷인·장면 셋은 GPT). 소담의 기술도 같은 방식(머슴 대장에게서 빚을 받아내자 우렁이 껍데기가 따뜻해짐). 큰 빚 앞에서 방망이가 금 가는 연출(`cutscene` broken). 출전 기본: 함께 싸우는 수 `PARTY_MAX` 4, 대기 식객도 경험치를 같이 받는다, 대사 줄 `with`로 데려간 식객에 따라 잡담이 갈린다, 소담의 집안일은 장터 값 한 할 깎기. 교체 화면은 식객이 넷 이상이 되는 5화 이후.

- **새 화 붙이는 규칙**: 새 화는 늘 대본 맨 끝 `{ t: 'end' }` 바로 앞에 붙인다. 그러면 끝까지 간 저장도 `revive()`가 새 화 첫머리부터 이어 준다. 저장 구조(`Game`)를 바꿀 때만 판본(`v`)을 올린다.

- **4화 시험판(B안, 2026-10-30)**: 첫 화면 '4화 시험판'은 1~3화를 기본 선택으로 건너뛰고 4화 첫머리에서 시작한다(`trialStart()`).
  - 그린 지도: `src/proto/maps/village_p.tmj`(그림 `public/proto/world/village.webp` 위에 32px 칸으로 걷는 칸·지점·인물·등잔·굴뚝). 걷는 칸은 그림을 보고 사각형으로 정했다.
  - SD: `public/proto/sd/`(게임용 240×360), 원본은 `art/sd/`. 도트 캐릭터 이름 → SD는 `src/proto/pixi.ts`의 `SD_OF`. SD가 없는 인물은 도트로 그린다.
  - 전투: 그린 지도에서 싸우면 지도 그림을 흐리게 깔고 SD로 그린다.
  - 협상 판: `src/proto/nego.ts`. 대본 비트 `{ t: 'nego', ... }`. 수단(방망이·백설 홀림·무영 위협·소담 장부)과 단서(깃발, 한 번만). 상대별 배율. 이기면 win, 지면 lose(어느 쪽이든 이야기는 이어진다). 대가는 `Game.rep`(평판), `Game.bsDebt`(백설에게 진 빚)와 깃발 `rep_down`, `bs_debt`로 뒤 대사에 돌아온다.
  - 작전: 선택지 `tactic`(push 몰아쳐라 · safe 목숨부터 · skill 기술 아끼지 마). 다음 전투에만 걸린다. 4화 밤 대장전은 작전 없이 가면 지기 쉽게 맞췄다(머슴 대장 Lv15, 세기 1.25).
