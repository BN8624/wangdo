# 왕도 제품 방향

2026-10-26 결정. **무료 체험판 + 한 번 사서 끝까지 하는 유료 완결형 본편.**

## 왜 이 방향인가

- 왕도의 강점은 이야기(26장)·식객 열여섯·인연 대본·그림이다. 끝까지 즐기는 완결 상품으로 팔기 좋은 자산이다.
- 현금 뽑기 운영형은 혼자·무료 도구로 감당하기 어렵다: 서버(계정·구매 기록·복구), 확률 공개 의무, 결제 문의·환불, 끝없는 새 식객·이벤트 공급이 필요하다. 광고형은 수익이 작고 성인 표현과 맞지 않는다.
- 완결형은 서버가 필요 없다. 저장은 기기에(스팀이면 스팀 클라우드) 둔다.

## 원칙

1. **현금 결제는 없다.** 게임 안의 옥으로만 모집한다.
2. **운에 기대지 않고 본편을 끝까지 간다.** 열여섯 식객은 모두 이야기와 만남으로 확정 합류하고, 별 재료는 장 완료(기억 조각 40)와 옥 → 기억 조각 교환으로 확정으로 얻는다. 모집은 더 빨리, 더 여러 식객을 만나는 덤이다.
3. **방치 보상·수련장은 선택 육성 수단**이다. 막혔을 때 돌아가는 길이지, 매일 들어와야 하는 의무가 아니다.
4. **구매자가 무엇을 받는지 분명하게**: 본편은 주요 갈등과 결말까지 담는다. 뒷이야기는 확장으로 더할 수 있다.

검증: 모의 플레이 '모집함'·'모집 안 함' 두 길이 모두 모든 장을 깨는지 테스트한다(`tests/data.test.ts`).
