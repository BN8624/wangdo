# 왕도 v2 설계

조선풍 판타지 궁중 권력 드라마 육성 게임. 산골 나무꾼이 도깨비 방망이를 주워 요괴 아가씨들을 식객으로 거느리고, 권세가 가문과 요괴 세력을 누르며 왕좌에 오른다. 왕이 된 뒤에도 이야기는 부(시즌) 단위로 계속 이어진다.

## 톤

- 대상: 성인. 로맨스·질투·암투·권력 판타지에 코믹을 섞는다.
- 식객(히로인)은 모두 20대 후반 이상의 성인 여성. 매력적이고 관능적인 분위기는 허용하되 노출·성적 묘사는 하지 않는다(대사로 암시하는 수준까지, 손잡기·포옹·입맞춤 직전 정도가 상한).
- 조선왕조·실존 인물·실제 역사는 쓰지 않는다. 나라 이름은 **해랑국**, 도성은 **한빛성**, 주인공 고향은 **달골**.
- 화면·글 어디에도 한자를 쓰지 않는다.
- 아이 같은 말투(~다구!, 뿅 등)와 전래동화 동화책 톤은 쓰지 않는다.

## 이야기 구조 (계속 이어지는 연재형)

- **부(season) → 화(episode)**. 한 화는 장면 몇 개(비주얼 노벨식 대사)와 선택지 하나 정도로, 3~5분 분량.
- 화마다 열림 조건(관직·권세·토벌 진행·앞 화)이 있어서 게임 진행에 맞춰 풀린다.
- 1부 방망이 주인(서민→현감), 2부 도성의 그림자(→판서, 송씨 가문과 암투), 3부 왕좌(→왕), 4부부터 왕이 된 뒤의 이야기(이웃 나라·용궁·하늘나라·북방 설원…).
- 새 화는 `content/story/<부>/<화>.json` 파일을 추가하면 끝. 코드 수정이 필요 없다.
- `npm run story:next`: Codex가 `docs/STORY_BIBLE.md`와 지난 화 요약(`content/story/summary.md`)을 읽고 다음 화를 같은 형식으로 쓴다. 매주 자동 실행도 가능.
- 마지막 화까지 보면 "다음 화 준비 중"이지만 게임 시스템(치세 단계, 끝없는 토벌, 주간 순위, 매일 정무)은 계속 돈다.

### 화 파일 형식

```json
{
  "id": "s1e01",
  "season": 1,
  "no": 1,
  "title": "방망이 주인",
  "summary": "다음 화를 쓸 때 참고할 두세 문장 요약",
  "unlock": { "after": "s1e00", "rank": 0, "power": 0, "stage": 0 },
  "scenes": [
    {
      "bg": "village",
      "cg": null,
      "cast": ["baekseol"],
      "lines": [
        { "who": "narration", "text": "지문" },
        { "who": "me", "text": "주인공 대사" },
        { "who": "baekseol", "text": "식객 대사" },
        { "who": "npc:송 대감", "text": "조연 대사" }
      ],
      "choice": {
        "prompt": "어떻게 할까?",
        "options": [
          { "text": "선택지", "reply": "선택 후 한 줄 반응", "effects": { "bond": { "baekseol": 10 }, "flags": ["spared_song"] } },
          { "text": "선택지", "reply": "선택 후 한 줄 반응", "effects": { "res": { "fame": 50 } } }
        ]
      }
    }
  ],
  "reward": { "coin": 500, "fame": 20, "recruit": null }
}
```

- `who`: `narration`, `me`, 식객 id, 또는 `npc:이름`.
- `bg`: `village`, `palace`, `market`, `tavern`, `field`, `night`, `forest`, `hall`(관아), `court`(어전) 중 하나.
- `choice`, `cg`, `reward.recruit`는 없어도 된다. `unlock.after`가 없으면 첫 화.
- 선택 결과는 `flags`로 남겨서 뒤 화에서 대사를 바꿀 수 있다(`"if": "spared_song"`을 줄에 붙이면 그 깃발이 있을 때만 나온다).

## 시스템

| 시스템 | 내용 |
|---|---|
| 관직 | 서민 → 방망이 임자 → 종9품 … 정1품 영의정 → 왕 → 치세 1·2·3단계…(끝없음). 권세와 명성이 차면 승급. |
| 권세 | 식객 능력치(무력·지략·정치·매력) 합. 수백에서 수천만까지 크게 오른다. |
| 일터 | 저잣거리(지략→엽전), 논밭(정치→곡식), 주막(매력→명성), 훈련장(무력→기력 회복). 적성·짝꿍 보너스. 자동 수입. |
| 정무 | 상소가 시간마다 쌓인다. 읽고 판결(두 선택지)하면 보상. 기존 '뚝딱 소원'을 대신한다. |
| 인연 | 대화·선물·나들이·연회로 호감도 5단계, 단계마다 개인 이야기와 특별 그림. 능력치 보너스. |
| 모집 | 초대장으로 식객 영입 연출. 겹치면 각성 조각. 매일 무료 1회. 이야기로만 얻는 식객도 있다. |
| 토벌 | 식객 셋을 세 판(무력·지략·정치·매력)에 배치, 2판 승리. 부마다 장이 있고, 다 깨면 끝없는 토벌. |
| 원정 | 식객 팀을 지역에 몇 시간 보내 재료·선물·초대장을 얻는다. |
| 순위 | 이웃 가문(NPC)과 주간 권세 경쟁. 순위 보상. 이야기의 라이벌과 연결된다. |

## 화면

- 시안 v2.1 기준(`docs/mockup-v2.1.jpg`): 궁궐 배경 위에 대표 식객 전신, 반투명 짙은 패널, 큰 흰 글씨, 금색은 숫자·강조에만. 한자 없음.
- 아래 탭: 궁궐 · 식객 · 인연 · 원정 · 순위. 메인 이야기는 궁궐에서 '이야기' 버튼으로.

## 그림

- 웹툰·서브컬처풍, 화려한 퓨전 한복, 어깨·다리가 드러나는 실루엣까지 허용(노출 없음).
- 식객마다: 배경 없는 전신(궁궐·장면 위에 세움), 카드 그림(배경 있음), 인연 3·5단계 특별 그림.
- 배경: 궁궐·마을·저잣거리·주막·논밭·밤·숲·관아·어전.
